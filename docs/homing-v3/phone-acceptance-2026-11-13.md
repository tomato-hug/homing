## 驗收中修正的問題

1. 上游 regex 把程式碼區塊中的圖片路徑也改寫，並把本機絕對路徑拼成 `/http://…`。改為解析 Markdown 目的節點；只把 Homing 能力路由轉為服務地址，程式碼不改寫。
2. Markdown 預設大標題在窄屏過大。改用應用字級，補短標題與正文整體高度的渲染回歸。

三項連結回歸與標題回歸均經 RED→GREEN；Android **168 項測試零失敗／錯誤／略過**，Go build 通過。合成服務僅註冊兩個假 Agent；沒有調用真實 Agent 或向真實會話發話。
