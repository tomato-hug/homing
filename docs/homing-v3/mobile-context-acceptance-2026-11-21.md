# 手機會話上下文與本地整理驗收（2026-11-21）

本輪依使用者要求優化手機會話閱讀、快速整理及 App 內連結。使用者已明確選擇清空／移除只改手機顯示，不同步 Mac；Android 手機尚未連線，本輪不宣稱實機驗收通過。

## 已實作

- 手機首頁按電腦、Agent source、session ID 聚合通知，避免同一會話因 message／done 通知重複佔據列表。會話中保留收件起點與後續消息，按時間插入手機回覆；工具過程可展開，同一通知的相鄰輸出可合併。
- 首次收件記錄持久化。一般刷新不再下載完整舊 transcript；首次詳情使用收件事件錨點，只接受有版本及來源／會話身分的回應。
- 「載入前 10 輪對話」為明確操作。前插歷史使用穩定 item_key 合併；刷新保留已載入頁、閱讀位置及游標。過期游標或未知 reader 邊界保留畫面並顯示原因，不宣稱沒有更早歷史。
- 收件箱清空只保存手機本地截止位置；會話行、滑動與批量移除只保存本地隱藏位置。支援撤銷及恢復隱藏會話，新活動可重新出現。這些入口不呼叫遠端 read/archive/delete，既有長按明確歸檔操作仍獨立存在。
- 已請求的歷史快取不再截成末尾 300 筆，Room 使用穩定鍵。草稿及延遲保存任務按電腦／來源／會話隔離；舊未指定來源的 transcript 快取不會繞過新邊界。
- 既有 WebView 完成系統返回、返回會話、錯誤重試與導航檢查。初始網址、地址欄、跳轉只接收 HTTP(S)。代理令牌僅發往已核對來源與端口路徑，重定向與不支援的表單方法明確失敗。

## 公網與 Mac

公網入口為 `wss://homing.douqu.online/v1/ws`。本輪 opt-in `TestPublicRelaySmoke` 通過五部分：認證握手與未配對拒絕、配對與加密收發、離線重送／確認／重連、撤銷拒絕、六位碼配對。測試使用生成的 peer 並撤銷測試配對。

Mac 管理頁在獨立瀏覽器中驗證會議紀要、已完成派發與 API 結果。關閉該管理頁後，隔離常駐服務及公網 health 仍回 200。這證明瀏覽器管理頁無須一直開著；Mac 常駐服務仍需在線。未啟動已安裝的 0.7.0 Tauri App，沒有把瀏覽器關閉結果當作原生 App 關閉／退出驗收。

目前 Mac 房間頁沒有直接顯示行動項狀態／輸出；協作頁僅顯示通用完成文字。測試輸出的正確性由認證 API 核對，未把它當作桌面 UI 已完整展示。原有背景通知需前台重連及部分 ACP 中間執行狀態的限制維持追蹤。

新增歷史接口也通過實際公網加密 RPC：生成的臨時手機 peer 完成 WSS 101、簽名握手及 host 指紋／SAS 核對，透過公網讀取隔離 Mac 的既有合成 Codex 行動項。初始回應 200、`history_version=1`、匹配錨點且僅 1 條；顯式前翻回應 200、1 個完整輪次／6 條，正確標示 reader 邊界未知。這個既有測試會話只有一輪可回溯，沒有把它說成公網跑過 10 輪。測試 peer 已撤銷，撤銷後流量被 `not_paired` 拒絕。

`/health` 不在加密 RPC 的 `/api/*` 允許範圍，探測回 403 符合現有策略；loopback health 及外部 HTTPS health 的 200 與此分開記錄。

## 後端配套與可用範圍

完整的向前分頁需要更新 **Mac 常駐服務** 的 `/api/sessions/{id}/items`；雲端中繼不負責解析會話歷史。後端三檔補丁已在乾淨隔離副本完成 build、API 全套、13 項歷史測試、race 與 Go 全套測試。使用者已依 AGENTS.md 的目錄歸屬規定同意接手 `internal/api/sessions.go`、`session_history.go`、`session_history_test.go`。補丁已套入共享工作樹，再次通過 API 全套、race 與 build，並已更新供測試配對使用的隔離 Mac 常駐服務（127.0.0.1:18888）。8787／18787 的原有服務未變更。

舊 Mac 服務下，新 Android 保留已收到的消息並提示更新，不使用伺服器忽略參數後回傳的完整舊內容。部分 reader 只能讀約 2 MiB 尾部，部分 parser 已裁剪正文；本輪無法恢復被來源丟棄的原文。合成 Hermes 派發已完成，但舊 API 的歷史條目為空，不能宣稱 Hermes 任意深度歷史已可讀。

電腦 localhost 網頁仍需要既有直連 HTTP 端口代理；公網中繼的 `/get` 是配對／安裝頁，不是 Mac 網站通道。重定向、表單、WebSocket、受保護下載未擴充。
